A screenshot tool you can read before you run it.

Shotty freezes the screen, dims it, and lets you draw on the region you selected — before anything reaches your clipboard or your disk. It also OCRs that region with the indentation intact. It is one Swift file, 393 lines, no dependencies, and it never talks to a server.

Those three commands are the entire pitch. Run them before you run anything else.

The gesture, on this page

Press the hotkey and the screen freezes and dims. Drag a box. Your selection stays lit, and you draw on it there. Nothing has been copied or saved yet, and nothing will be until you say so. Try it below: this is the same interaction, and the screen you are marking up is Shotty's own source.

var out: [String] = [] var prevY: CGFloat? for line in lines { let row = line.sorted { $0.x < $1.x } guard let first = row.first else { continue } if let py = prevY { // blank lines in between let blanks = Int(((py - first.y) / lineH - 1.4).rounded(.down)) if blanks > 0 { out.append(contentsOf: Array(repeating: "", count: min(blanks, 3))) } } prevY = first.y var text = "" for p in row { let col = Int((p.x / charW).rounded()) // column from the left edge if col > text.count { text += String(repeating: " ", count: col - text.count) } else if !text.isEmpty { text += " " } text += p.s } out.append(text) } return out.joined(separator: "\n")

OCR that keeps the columns

Vision returns recognized text as a bag of bounding boxes, so the straightforward implementation pastes back a flattened blob. Shotty estimates character width from the median box, maps every fragment back to a column, and reprints the block, so indentation, column gaps and paragraph breaks survive and a screenshot of code comes back as code. The whole OCR path is 80 lines; the column reconstruction itself is Overlay.layout(_:), 44 of them.

Character for character, column for column: that identity is the entire feature. Try to select the left panel and you cannot, because it stands for pixels; the right one is real text. Small selections are upscaled 2× before recognition, and language correction is off by default so it stops "fixing" your identifiers. One flag at the top of the file turns it back on if you mostly capture prose.

Install

There is no signed installer yet. You build it, which takes a few seconds and means you can read what you are running first.

  1. Get the command line tools if you don't have them.xcode-select --install
  2. Clone and build. build.sh is 22 lines: swiftc plus an Info.plist.git clone https://github.com/uuu4/shotty.git cd shotty && ./build.sh && open Shotty.app
  3. Grant Screen Recording on the first capture: System Settings → Privacy & Security → Screen Recording. Then open it once more. Shotty lives in the menu bar as ✂︎, with no Dock icon. macOS 13 or later.
